## 10. 明确不修改的执行面

- scientific kernels 和 node registry plugins；
- Pipeline Runtime 和 node runners；
- Sandbox Process Runner 和 Windows restricted-token 实现；
- Execution Gateway dispatch 算法；只允许在 `dispatch()` 内、`tickets.consume(...)` 之前调用 `TeamTicketPolicyVerifier`，不新增第二 dispatch 路径，也不在 Gateway 上新造 `consume()` 方法；

- 应用版本和 Release 产物。
