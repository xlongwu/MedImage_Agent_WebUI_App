## Current Implementation Note (2026-06-15)

The Phase 6B DICOM conversion path has moved from planned/risky to verified for the real DemoData conversion case. With all maintainer execution flags enabled, the public conversion endpoint now converts `data/DemoData` from 1104 DICOM files into 6 NIfTI outputs and 6 JSON sidecars, while leaving rawdata unchanged.

Important corrections made during verification:
- non-empty audit preview IDs are required and persisted;
- dcm2niix `-b` and `-ba` flags are emitted as `-b y` and `-ba y`;
- dcm2niix stdout/stderr errors fail execution even with return code 0;
- missing expected NIfTI files fail execution;
- empty persisted mappings/templates are blocked;
- the strict public E2E test now requires real outputs rather than accepting blocked responses.

This does not complete Phase 6C or Phase 6D. Full preprocessing-to-report execution and algorithm golden validation still require their own verification.
