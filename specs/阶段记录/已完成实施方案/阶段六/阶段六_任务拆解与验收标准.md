## 总体策略

### 执行顺序（严格串行，不可并行）

```
Phase 6A  工程规则和 CI 稳定
    ↓（依赖：无）
Phase 6B  真实 DICOM 转换闭环
    ↓（依赖：6A 完成 + 转换输出作为预处理输入）
Phase 6C  真实预处理链闭环
    ↓（依赖：6B 完成 + 算法在真实数据上验证）
Phase 6D  算法标准化和 RC 冻结
```

**不可并行原因：** 6B 的转换输出是 6C 的输入，6C 的预处理结果是 6D 验证的数据基础。并行会导致输入、中间输出和算法结果同时变化，无法定位问题。

### 每个任务的开发方式（完整垂直切片）

每个任务交付一个**用户可实际完成的完整能力**：

```
需求 → API contract → schema → service/runtime → route → frontend → persistence → edge cases → focused tests → unified regression → local EXE smoke
```

**不拆成：** 先加 schema → 下个任务加 service → 下个任务加 endpoint → 下个任务加 UI → 下个任务 UI closure。

## Phase 6D — 科研算法标准化与 RC 冻结

### Task 6D: 科研算法标准化与 RC 冻结

**Description:**
将"流程能运行"提升为"结果具备科研可信度"。为 5 个优先算法补充标准化实现，创建 golden dataset，与参考实现对比验证，最后冻结形成 v0.6.0-rc1。

**Acceptance criteria:**

Nuisance Regression 标准化:
- [ ] motion 6/12/24 参数可选
- [ ] WM/CSF/global signal 可选
- [ ] polynomial trends
- [ ] censoring/scrubbing
- [ ] design matrix rank 检查
- [ ] residual DOF 计算
- [ ] 共线性警告

Temporal Filtering 标准化:
- [ ] TR 自动读取
- [ ] Nyquist 校验
- [ ] Butterworth 或 FFT filter（可配置）
- [ ] 边界效应策略
- [ ] filtering 与 regression 顺序明确

ALFF/fALFF 标准化:
- [ ] FFT → amplitude spectrum → target frequency band → ALFF
- [ ] whole spectrum denominator → fALFF
- [ ] optional z-standardization

ReHo 标准化:
- [ ] Kendall's coefficient of concordance (KCC)
- [ ] 7/19/27 neighbors 可选
- [ ] mask 支持
- [ ] edge handling
- [ ] tie correction
- [ ] optional normalization

FC 标准化:
- [ ] Atlas parcellation
- [ ] ROI time series extraction
- [ ] confound-aware valid timepoints
- [ ] Pearson + Spearman 可选
- [ ] Fisher-z
- [ ] ROI × ROI matrix

Golden Dataset 验证:
- [ ] 为每个算法准备小型固定数据集
- [ ] 与 Nilearn 对比（必做，Python 生态可直接集成 CI）
- [ ] 与自建 NumPy reference 对比（必做，作为 baseline）
- [ ] 与 DPABI 对比（Optional — MATLAB 环境不可用，可后续手动补充）
