## 归档规则

1. 只有文档声明的当前范围有明确完成或正式“延期/拒绝进入下一 Gate”的闭环结论时才归档。
2. 源码完成、科学验证、packaged smoke 和 release acceptance 分级判断，不互相替代。
3. 部分完成阶段不整目录归档；未完成的独立提案继续留在原阶段目录。
4. 归档移动后必须更新导航和相对链接，并检查不存在仍指向旧路径的引用。
5. 单份文档自身声明的范围闭环即可逐份归档，不要求整个阶段目录闭环；归档时必须在顶部写明仍未取证
   的 ③ packaged/release 与 ④ 科学验证事项，并把需要人工取证或人工拍板的条目登记到
   `specs/待人工审核校验清单.md`，避免同一待办在索引、归档说明和方案标头出现互不一致的版本。
