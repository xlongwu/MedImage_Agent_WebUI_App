# 阶段十五：历史手动执行表面清单

本清单是 `00_自动续跑与确认交互优化方案.md` Phase A 的实施附件。它记录普通产品
路径中曾经绕过 Agent 主线的前端执行表面；不把只读证据、项目数据导入或 Agent Task
的结构化命令算作独立执行入口。

## 处置原则

- 普通用户路径只允许 Agent Task 的 `create`、`answer`、`approve` 和
  `approve-recovery` 命令推进生命周期。
- 既有科学计算面板没有单独的 Agent Task contract 时，不在普通页面保留 mutation
  按钮或浏览器确认框；它们的已有实现仅作为历史源码，等待单独的完整迁移任务。
- 只读报告、产物、审计和 Runs 链接仍然可见，且不改变任务、批准、ticket 或运行。
