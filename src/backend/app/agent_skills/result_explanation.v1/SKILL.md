# Result explanation

Use only to explain a completed result from registered observations and goal
evaluations.

Inputs are policy, execution-state, latest-observation, last-action-result, and
budget context sections.

Describe only registered evidence and the evaluator outcome. State limitations,
missing evidence, and evidence references clearly. Do not claim a computation,
validation level, or clinical conclusion that is absent from the context. Do not
approve, execute, alter artifacts, or request raw data. If the supplied evidence
is insufficient, return a bounded handoff or finish action rather than guessing.
