# 处理流程图

处理流程图是审阅计划和运行状态的只读投影。它不会创建计划、审批、执行票据、运行或产物，也不会修改 `rawdata/`。

- 计划结构仅来自已验证的 `payload.plan.nodes` 与 `depends_on`。
- 运行状态仅来自 `state-store-v2` 节点状态文件；运行链接固定绑定项目、`reviewed_plan_id` 和计划哈希。
- 节点执行器调用前原子写入 `RUNNING`，结束后以相同文件覆盖为终态。进程中断留下的 `RUNNING` 记录如实显示为陈旧状态警告。
- API：`POST /api/projects/{project_id}/plan-graph-preview`、`GET /api/projects/{project_id}/plans/{reviewed_plan_id}/graph`、`GET /api/projects/{project_id}/runs/{run_id}/graph`。
- 前端使用只读 React Flow 画布和与之等价的表格；运行图按三秒串行读取，终态停止，网络错误保留最后一次成功投影。

图结构变化由 `structure_hash` 表示，状态变化由 `state_hash` 表示；仅状态变化时不重新布局或重置用户视口。图中不包含绝对路径、完整参数、日志、凭据或研究数据。
