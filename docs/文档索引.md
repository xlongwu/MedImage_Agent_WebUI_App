## 使用原则

- 当前能力和限制优先查看根目录的 `PROJECT_STATE.md`。
- 当前规划入口只有项目级 Agent Task；请通过任务详情、Approval Summary 和项目 Runs
  查看规划和运行证据，不使用已移除的文件型 Agent plan/run 路径。
- 历史发布记录和阶段完成记录只说明当时状态，不覆盖当前代码和规则。
- 标题或页首标记为 Design、Draft、Audit、Baseline、历史状态的文档只保存当时的设计或
  审计证据；路径、接口和能力结论必须回到系统架构、能力矩阵、项目状态和当前源码核实。
- `预处理与科学计算/DICOM转换/` 中标记 Historical/Superseded 的 `dcm2niix`
  文档仅供审计；当前实现是项目内 Python converter 与唯一 reviewed gateway。
- 临时任务完成后应删除；需要长期保留的结论应迁移到架构、决策、用户指南或发布记录。
- 已完成实施方案不保留为现行文档；长期约束进入 `specs/规范/`，里程碑结果进入
  `specs/阶段记录/`，被当前架构和状态文档取代的分析直接清除。
- [`specs/规范/`](../specs/规范/) 保存正式科学与工程规范，[`specs/阶段记录/`](../specs/阶段记录/) 保存经批准的阶段级记录。
