# Native Preprocessing Resource Policy

Status: Phase 11 resource boundary.

Phase 03 did not add bundled MNI templates, tissue priors, or atlas resources
to the repository.  Phase 11 has one reviewed exception: the SPM12
`avg152T1.nii` reference used only by automatic ACPC alignment.

The ACPC reference is packaged at
`src/backend/app/native_preproc/resources/acpc_reference/avg152T1.nii` with
the checksum-pinned manifest `spm12_avg152_t1_ras.json`.  The manifest fixes
the template identity, `RAS+ mm` coordinate convention, AC `[0, 0, 0]`, PC
`[0, -24, 0]`, and an MSP normal.  It is a template-reference resource, not a
manual landmark reference set and not evidence that individual landmark
estimates are scientifically validated.

Apart from that narrow ACPC exception, API and reviewed workflow may pass
caller-supplied template or atlas paths, but MedImage Agent does not bundle
AAL, Schaefer, Brainnetome, other MNI templates, or tissue priors.

The native spatial stages accept caller-supplied resources:

- affine normalization accepts a caller-supplied template image;
- atlas resampling accepts a caller-supplied atlas image;
- segmentation V1 uses image intensity only and does not use bundled tissue
  priors.

Any future bundled template, tissue prior, or atlas must be reviewed for:

- source and version;
- license and redistribution terms;
- package size and CI impact;
- checksum and provenance identity;
- interpolation requirements for continuous images versus labels;
- whether it is a test fixture, optional runtime resource, or release asset.

Synthetic fixtures in unit tests are generated in test code and are not
scientific reference templates or atlases.

Current capability labels must remain truthful:

- segmentation is `simplified`;
- normalization is `affine_only`;
- atlas resampling is nearest-neighbor label resampling only;
- none of these stages are SPM/DPABI reference validated.

## Phase 05 Atlas and Label Policy

Phase 05 adds atlas-grounded ROI time-series and FC stages, but still does not
bundle AAL, Schaefer, Brainnetome, or other third-party atlas resources.

Current Phase 05 behavior:

- accepts caller-supplied 3D integer label atlases;
- accepts optional caller-supplied TSV or JSON label files;
- records empty ROI labels as warnings instead of silently dropping them;
- uses synthetic atlases generated inside unit tests for validation only;
- does not claim bundled atlas availability or reference validation.

Bundled atlas resources remain blocked until source, version, license,
redistribution terms, package size, checksum identity, and CI/release packaging
strategy are explicitly approved.
